### Source code for GDELT dataset preprocessing and case studies
This repo accompanies the GDELT case studies in (tentative title): Directional Neighborhood Time Series on the Sphere for Bayesian Count Regression and Anomaly Detection: Evidence from GDELT Event Panels, by Hsin-Hsiung Huang, Yuh-Haur Chen, and Mahlon Scott.

The dataset_pipeline folder contains all code required to download and preprocess the data, spatially aggregating event counts by spatiotemporal region, actor country, and event code.

The experiments folder contains the source code and checkpoints for all models used in the paper.
